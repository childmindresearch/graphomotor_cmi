# ReadMe

### Graphomotor Protocol Child Mind Institute Summer 2025

This repository is for the Graphomotor Protocol that the Child Mind Institute is conducting starting in Summer 2025. This repo has a script "graphomotor_full.py" which contains the entire protocol. This protocol is a custom software that was created to replace PsychoPy. This version is flexible enough to accommate several different types of visual and audio stimulus presention - still images, audio files with text images, and videos.
